# Real Slate screenshot handoff

Use Slate manually launched in the normal interactive Windows user context. Do not use a Codex-launched instance for production-library screenshots, or alter private clips to manufacture marketing data.

Use already-approved non-personal sample clips or a separately approved demonstration library. Remove account names, personal paths, sensitive URLs/query strings, clip contents and notifications before sharing screenshots. Do not assume cropping safely anonymizes a private library.

Capture PNG at 100% display scale where practical; retain native pixels, not enlarged/resampled images. Keep the app frame and exclude desktop/taskbar unless demonstrating a notification. Future screenshot assets belong under public/product, never release directories.

The approved compact page needs only one real screenshot:

| Shot                    | Window/theme    | State and crop                                                                                         | Replacement |
| ----------------------- | --------------- | ------------------------------------------------------------------------------------------------------ | ----------- |
| Main library / Calendar | 1440×960, light | Current month, several safe clips, sidebar and selected clip with source/date. Full application frame. | Hero        |

The user will supply two short silent recordings for the existing feature cards: browser capture of safe sample text from ChatGPT/Claude, and Quick Search opening/finding a safe saved clip. Use local MP4/WebM files under public/product, with useful poster frames, visible playback controls and no autoplay. Avoid accounts, personal clip data and unrelated browser/profile UI. Until supplied, the cards explicitly say “Video coming soon”; do not fabricate footage or broken video URLs. Desktop Capture uses a static keyboard-shortcut visual, not a third video. Group-detail screenshots are not needed for the current page.

Remove the illustration/sample-content caption only when its replacement is a real screenshot. Add useful alt text, keep sources legible without exposing personal information, and recheck mobile crops/file size.
